# 会话交接

生成足够让下一会话继续工作的交接文档，包含当前目标、用户约束、已完成事项、
关键证据、相关文件、未决问题和下一步；不要把未验证的推断写成已完成结果。

优先使用用户给出的路径；未指定时创建临时目录并将文档保存在其中，返回实际路径。
覆盖已有文件前先读取并确认用途，不把交接文档写入全局指令或技能目录。

已保存在 PRD、计划、ADR、工单、提交或差异中的内容只引用路径或链接，不重复抄录。
有需要时提示下一会话使用哪些已安装技能；交接本身不安装技能、不发布到外部系统。
用户说明下一会话重点时据此裁剪；保留恢复工作需要的信息，不记录密钥或无关隐私。
